# تصحيح المشرف لسجل الطالب

من الحلقة ← الطالب ← سجل الطالب ← اليوم ← «تصحيح هذا اليوم».
يمكن تصحيح مدى تسميع موجود، النتيجة المستقلة للحفظ أو المراجعة، الغياب والحضور، الملاحظة، وواجب اليوم التالي. لا تُضاف أنشطة افتراضية، ولا تُحذف محاولة سابقة. يبقى تقدير المحاولة الأصلي محفوظًا؛ تصحيح النتيجة النهائية مستقل عنه.

يقتصر التصحيح على يوم مسجل حالي أو سابق. الحاضر يحتاج مدى تسميع قبل اعتماد نتيجة، وطالب المراجعة فقط لا يقبل حفظًا جديدًا. لا يُحوّل طالب له تسميع إلى غائب. يمكن إلغاء غياب بلا واجب سابق.

التصحيح الإداري لا يرحل الواجب آليًا ولا يعيد كتابة الأيام اللاحقة. يستطيع المشرف تصحيح الواجب صراحةً، ويظهر موعده وفق سياسة اليوم الأصلي. يبقى إغلاق اليوم القديم كما كان، ويعاد فتح اليوم الحالي المصحح لمراجعة المعلم.

يُحفظ معرف المشرف والتاريخ والإجراء ونسختا السجل قبل التصحيح وبعده داخل معاملة واحدة. بصمة السجل تمنع الكتابة فوق تعديل أحدث، وتعارض المعاملات يطلب إعادة فتحه. لا API لتغيير أثر التعديل أو حذفه. صلاحيات المعلم وحدود أيامه تبقى كما هي؛ واجهة التصحيح لا تقبل جلسة معلم وتتحقق من Origin لكل كتابة.

هذه الخطوة لا تشمل نقل الطلاب أو الاختبارات أو الاعتمادات أو الشهادات.
