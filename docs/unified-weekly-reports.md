# التقرير الموحد وتنسيق ملفات PDF

التقرير الموحد ملف واحد: ملخص القسم ثم جميع الحلقات وطلابها. يتجاهل الخادم فلاتر الحلقة والطالب لهذا النوع كي لا يصبح تقريرًا جزئيًا دون قصد. تبدأ كل حلقة بصفحة جديدة، وتستمر الجداول مع تكرار اسم الحلقة ورؤوس الأعمدة عند الحاجة، دون إسقاط طلاب أو قص الملاحظات الطويلة؛ تظهر الملاحظات المطولة بعد الجدول.

الموحد A4 عرضي. تقارير المتابعة والتميز والغياب والطالب A4 طولية، ولكل منها محتوى يناسب موضوعه. تبقى تقارير الأهل اليومية بتخطيطها القائم. تُحوّل أرقام جميع ملفات PDF إلى 0–9، بما فيها التواريخ والمقادير والمديات والملاحظات؛ لا تتغير بيانات قاعدة البيانات.

الفترة الافتراضية الأسبوع السابق من الاثنين إلى الجمعة. «هذا الأسبوع حتى اليوم» متاح بوسم واضح، والشهر والفترة المخصصة مستمران. الأسبوع الكامل من الاثنين إلى الجمعة يحمل عنوان «التقرير الأسبوعي الموحد».

التعريفات:
- يوم الطالب المتوقع: يوم دراسة الاثنين–الجمعة كان فيه الطالب ضمن قيد الحلقة، مع إعادة بناء النقل عبر سجله. القيد السابق غير النشط بلا تاريخ معروف تُستخدم أيامه المرصودة فقط، ولا نفترض غيابًا.
- اليوم المسجل: فيه نتيجة أو تسميع أو ملاحظة؛ السجل الفارغ لا يعد تسجيلًا.
- اكتمال التسجيل: مطابق لقواعد تقرير المعلم من نتائج ومديات وواجب الحصة التالية، مع احترام تقارير الإغلاق القديمة. الغائب لا يحتاج واجبًا سابقًا. اكتمال الدوام محسوب لأيام الدراسة المتوقعة.
- الحضور: حضور مؤكد بنتيجة يوم أو تسميع أو نتيجة نشاط. الملاحظة وحدها لا تثبت حضورًا. مقام النسبة الحضور والغياب المسجلان، ويستبعد غير المعروف.
- حافظ في الحفظ والمراجعة: نتيجتان مستقلتان؛ لكل منهما مقام الأيام المقيمة الصحيحة فقط. طلاب المراجعة فقط مستبعدون من مقام الحفظ. المقام صفر يظهر «لم تسجل» أو شرطة بدل نتيجة مختلقة.
- مقدار الصفحات: مجموع الأنشطة الفعلية المتكررة في الفترة، مقرب لمنزلتين؛ ليس اعتماد إتمام أو شهادة.

تقرأ البيانات والعضوية والواجبات في لقطة RepeatableRead واحدة؛ لا يفتح التقرير يومًا ولا يكتب نتائج. الطلاب المنقولون لا يتكررون في إجمالي عدد الطلاب، وتبقى سجلات الحلقات الأصلية ظاهرة.

معايير تصفية المتابعة والتميز الحالية لم تتغير ولا تعد سياسة مدرسية معتمدة. إعادة اعتماد المعايير التربوية خطوة لاحقة.
